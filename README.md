# ChunkLoader (Paper 1.21.11)

Haelt Chunks dauerhaft geladen (Plugin-Chunk-Tickets). Die Chunks bleiben auch nach einem Neustart erhalten.

## Befehle (Permission `chunkloader.use`, Standard: OP)
- `/chunk load [radius]` - Chunk, in dem du stehst, dauerhaft laden (Radius 1 = 3x3 Chunks)
- `/chunk unload [radius]` - wieder freigeben
- `/chunk list` - dauerhaft geladene Chunks in deiner Welt

## Config
- `max-radius` - groesster erlaubter Radius
- `max-chunks` - Limit fuer den ganzen Server
